# Apply Flow

Apply Flow is a modern job application tracker designed to help students and early-career professionals stay organized during their job search.

## Features
- Track applications by stage: Saved, Applied, Interviewing, Offer, Rejected
- Add, edit, and delete applications using a clean modal interface
- Search and filter your application pipeline
- Responsive, dark-themed UI
- Built with accessible and reusable UI components

## Tech Stack
- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui (Radix UI)
- Lucide Icons

## Current Status
Apply Flow currently uses frontend state for managing applications.
Backend persistence (Supabase) is planned for a future version.
